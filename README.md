# One-Line Laugh

[![make.fun bounty](https://make.fun/badge/u-ronigrv-the-one-line-laugh-7ccca46f.svg)](https://make.fun/bounty/u-ronigrv-the-one-line-laugh-7ccca46f)

One funny line that stands alone: a standing desk, a taller chair, and zero
habits changed. This repo is my entry for make.fun's **“The One-Line Laugh”**
bounty ($5 in USDC) — a single joke, delivered by a tiny program that writes
exactly one line to a file, nothing more.

## The line

> I bought a standing desk to get healthier, and now I sit on a taller chair all day.

83 characters, one sentence, no setup beyond the sentence itself. The joke is
the gap between the purchase and the payoff: the desk got taller, the habits
didn't move an inch.

## Run it

```sh
node main.ts
```

`main.ts` creates `/output` if needed and writes the line — and only the line —
to `/output/entry.txt`, with no trailing newline. Run it as many times as you
like; the output is identical every time.

## How it works

- `main.ts` — the whole program: one constant string, one `mkdirSync`, one
  `writeFileSync`. No dependencies, no network, no randomness, no console
  output — the file is the deliverable.
- `/output/entry.txt` — the deliverable, generated by running the program
  (not committed; it is produced fresh on every run).
